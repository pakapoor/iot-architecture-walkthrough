WHY IT'S BUILT THIS WAY
⏱ Timers, not polling
"Device down > X min" is a per-device timer in Flink state. No scanning 100M rows in a DB — why Flink beat Kinesis + Lambda.
🚨 Two alert lanes
Critical pages on-call instantly. Minor issues roll into 15-min site digests. No alert storms, no 3 AM pings.
🔁 Idempotent actions
Correlation ID = device + window. Retries upsert the same ticket; failures go to a DLQ with alarms. Zero duplicate tickets.
💰 Pay for what's hot
7 days hot for live views, 6-month rollups, sampled cold archive. Tiered retention bounds hot-storage cost per device.
🛟 Degrade, don't die
Edge buffers through outages, standby gateway takes over, Kafka replays. Bounded buffering + failover; recovery is monitored.
Observability: consumer lag · checkpoint health · throughput · end-to-end trace ID (edge → ticket)
Deployment: independent services on K8s · global region + isolated China region
